# RTrino: 'DBI' Backend for 'Trino'

A 'DBI' compliant backend for 'Trino' <https://trino.io>, the
distributed SQL query engine (successor of 'PrestoSQL'). Connects to a
'Trino' cluster over its HTTP REST API, executes queries with automatic
pagination, maps 'Trino' types to R types, and integrates with 'dplyr'
through 'dbplyr' SQL dialects. Supports basic, JSON Web Token (JWT)
bearer and OAuth2 client credentials authentication, as well as custom
certificate authorities.
